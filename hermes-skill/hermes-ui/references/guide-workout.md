# guide, workout, recipe, timer (hands-on and doing)

## guide (interactive step-by-step; replies `[guide:<id>] Schritt 3 („…“): Ich hänge fest – <detail>` = step 3: stuck, and `[guide:<id>] Fertig` = done; fixed protocol words, answer in the user's language)
{id, title, intro?, stuckLabel?, steps:[{id?, title (<=200), body (markdown, <=2000), imageQuery?, tip?, warning?, seconds? (inline timer 1-86400)}] (<=20)}
- For hands-on procedures the user performs while reading: repairs, assembly, device setup, cooking technique, first steps in a tool. 4-12 steps, ONE action per step, `title` = the imperative ("Remove the wheel"), `body` = 1-3 sentences with the how.
- `warning` for safety/irreversible risks, `tip` for a shortcut, `seconds` when a step waits (glue dries, rest the dough), `imageQuery` only where a photo really helps. Reference-style or tech install lists: `steps`; cooking with ingredients: `recipe`.
- Stuck reply: answer exactly for that step (cause + fix, ask one question if needed), don't re-show the guide. Done reply: congratulate briefly, offer a next step.

## timer (reply: none; the app notifies when it ends)
{id, label, seconds (1-86400; 0 or omit with until/stopwatch/timers), until?: ISO datetime, mode?:"countdown"|"stopwatch", timers?:[{id?, label, seconds}] (<=6), autostart?}
- Single: `seconds`. Countdown to a date/time ("until kick-off at 20:45"): `until` (ISO local, e.g. "2026-10-17T20:45"), only with a date you know. Stopwatch: `mode:"stopwatch"`. Several at once (menu, intervals): `timers` of 2-6 with a short `label`. Never `autostart:true` (the user taps start).
- "Remind me in 10 minutes" is a reminder/timer request: if the user wants a countdown, use `timer`; a reminder at a clock time stays text + `reminder` action button.
- Changing a timer you showed ("make it 3 minutes"): the same `id` with the new `seconds`; the app replaces the running one. Another timer: its own `id` and `label`.
