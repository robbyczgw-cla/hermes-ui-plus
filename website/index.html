№ 06

Run the bridge

There is no hosted service. You run a small Node.js service, the bridge, next to your Hermes (Node.js 22+ or Docker). It authenticates your devices, routes presentation, handles uploads, voice and push, and pairs a new phone with a QR code. We strongly recommend reaching it over Tailscale and never exposing it to the public internet.

on the machine that runs Hermes

$ npx hermes-ui-plus-bridge setup
  1. Turn on the Hermes API server and start the Hermes gateway.
  2. Run the setup wizard on that machine: npx hermes-ui-plus-bridge setup.
  3. Install the app and scan the pairing QR code.

№ 07

Give this to your agent

Hermes can run shell commands, so it can set up its own bridge. Paste this prompt into a direct chat with your Hermes (Telegram, Hermes CLI) or into a coding agent with a terminal on the same machine.

  • Checks the prerequisites first and tells you what is missing
  • Asks before installing packages or restarting Hermes
  • Stays on your tailnet: no funnel, no port forwarding
  • Never shows keys or tokens; hands you the one-time pair link
  • Ends with what it installed, where, and how to undo it

Variants for Hermes and for coding agents, plus diagnosis and update prompts: SETUP-WITH-AGENT.md

№ 08

Privacy in short

The developers collect no data. There are no accounts, no analytics, no advertising and no crash reporting. Your messages go from your device to your bridge, then to your Hermes, and from there to the model providers you configured. Nowhere else.
