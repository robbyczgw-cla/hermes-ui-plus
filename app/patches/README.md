# Dependency patches

Applied by `patch-package` (app `postinstall`, so every `npm ci` – build scripts, CI – installs patched sources).
A patch file is named `<package>+<version>.patch` and only valid for exactly that pinned version;
`scripts/dependency-patches.test.mjs` fails when a version changes, so each bump revisits its patch.

| Patch | Why | Remove when |
|---|---|---|
| `expo-share-intent+8.0.1.patch` | Android module hardening for "Share to HUI+" (docs/SHARE-TARGET.md): a content provider without a cursor, a name/size column or a MIME type, or a file that cannot be opened, threw on the main thread and crashed the app; it now reports an error (the app shows a notice). `text/*` shares other than `text/plain` that carry only `EXTRA_TEXT` (no stream) arrive as text instead of an error. Shared files use unique temporary paths so same-name files never overwrite each other. Intake diagnostics omit file names, provider URIs and provider exception details. Also fixes the single-file payload (the `type` entry ended up inside the file array), keeps a missing display name empty (the app then reports the file as unreadable instead of "type not supported"), and marks a launch intent as delivered once JS has it: the activity keeps that Intent object across a recreation (font size change) and the lifecycle listener used to hand the same share over again. | Upstream handles these cases (check `getFileInfo`, `handleShareIntent`, `getShareIntent`, `getDataColumn` and the lifecycle listener). |
| `react-native-reanimated+4.5.1.patch` | Backport of [reanimated#10435](https://github.com/software-mansion/react-native-reanimated/pull/10435) (Android, RN ≥ 0.86): synchronous prop updates skip views that are no longer mounted. Without it every event dispatched during a draw pass (react-native-svg sends one per element on its first draw) re-applies Reanimated's whole props registry, and each entry of an unmounted view throws and logs a ~125-line stack on the UI thread ("synchronouslyUpdateUIProps failed for tag N … Unable to find SurfaceMountingManager"): hundreds per streamed answer. | Reanimated ≥ 4.7.1 (contains the fix). |
