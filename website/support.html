Support

Hermes Interactive UI+ is a volunteer project. Replies can take a few days.

Questions and bug reports

Use the GitHub issue tracker. It is public, so please redact tokens, host names and anything personal (use placeholders), and include the app and bridge versions and your platform. Search the existing issues first.

E-mail

For anything that is not suitable for a public issue, write to robby@robbyczesany.com. That is also the contact address for privacy questions.

Security problems

Please do not open a public issue for a vulnerability. See Security for how to report it privately.

Hermes Agent itself

This app is an unofficial client and is not affiliated with Nous Research. Problems with Hermes Agent itself belong to its own project.

Hermes Interactive UI+ is an unofficial, open-source community client for the Hermes Agent. It is not affiliated with, endorsed by or supported by Nous Research. No accounts, no analytics, no cookies, no trackers on this site.
