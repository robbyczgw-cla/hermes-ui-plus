# paths (2-6 ways / variants / architectures: verdict badge + node chain "A → B → C" + one note line)
{id?, title?, items:[{id?, title, badge?:{text, tone?:"neutral"|"good"|"warn"|"bad"}, path:[{label, icon?, detail?}] (1-6), note?}] (2-6), basis?, source?, select?:boolean}
- Use when options differ in HOW something flows or where it lives, and each gets a verdict: "where do the files live" (native vs VM disk vs shared folder), "how does a request travel" (app → bridge → server), Docker vs VM vs bare metal, which backup / sync / deploy route.
- Not for: 2-4 options with several pros/cons (`compare`), many attributes per option (`table`), ONE procedure to follow (`steps`/`guide`), one big drawing with branches (`hui-html` diagram), weighing by criteria (`decision`), a plain pick without chains (`choice`).
- 2-6 items, best order: baseline first, then alternatives. `title` 2-5 words. `path` 1-6 nodes in flow order, `label` 1-3 words (≤ 20 chars: "macOS", "virtiofs", "NAS"); `detail` only a tiny qualifier ("router + push"). `note` = ONE short line (≤ ~90 chars) with the reason for the verdict.
- `badge` = verdict in 1-2 words; tone: `neutral` grey = baseline / status quo ("Baseline"), `good` green = recommended / interesting, `warn` orange = works with caveats, `bad` red = avoid. Plain string badge = neutral. At most 1-2 `good`; text outside names the recommendation.
- `icon` (optional, else left out): laptop desktop phone server cloud disk folder file database network lock user globe app container vm terminal. Other names are ignored.
- Facts about the user's own setup come from the user or tools; general architecture knowledge is fine. `basis`/`source` like data nodes when the verdicts rest on numbers or sources.
- `select:true` (needs `id`, counts as the one input node): rows become a single choice; a tap sends `[paths:<id>] <title>`. Only when you need the pick to continue ("which backup route should I set up?"). Reply: confirm the pick in one sentence and give the first concrete step; never re-show the node.
- Text outside: 1-2 sentences with the recommendation.
